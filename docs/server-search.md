# PicoTera 中的搜索模拟

PicoTera 提供使用 Exa 或者 DeepSeek 兼容接口模拟 Anthropic 风格的服务端搜索工具。

## 前置条件

* 使用 unified 网关端点
* 渠道配置为“不支持原生 Web 搜索”
* 配置了 Exa 或者 DeepSeek 端点
* 有一个或多个渠道配置了 Exa 或 DeepSeek 端点的关联

当满足以上条件时，搜索模拟会自动激活。

## 支持情况

目前主要测试在 Claude Code 中搜索，尚未在其它场景下通过严格测试，但我们认为也可以兼容。

## 请求和计费

由于客户端 tool call 需要 agent loop，搜索模拟会产生多条元请求。

具体而言，客户端发起的元请求中，将记录其收到的完整响应，包括服务端工具调用、响应、后续总结信息等。
其中 PicoTera 自动发起的搜索请求、后续 LLM 调用，将会产生各自独立的元请求。

由客户端产生的元请求会将后续的 tokens 和计费全部统计在内，这会导致使用了模拟搜索的请求，tokens 和费用被重复计算一次：
客户端的元请求会记录一次，由 PicoTera 产生的请求又会记录一次。
