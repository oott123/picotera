# Proposal — 概览页面自定义时间范围

## 需求

为用户概览（`/overview`）和全局概览（`/admin/overview`）页面增加「自定义」时间范围选项。

- 时间范围分段控件在现有「24 小时 / 7 天 / 30 天」之外增加「自定义」。
- 选中「自定义」时，控件下方出现开始时间和结束时间选择框（与请求页面、追踪页面一致，复用 `TimeRangeFilter` 组件）。
- 选中预设范围时，不显示开始/结束时间选择框，行为与现在完全一致。
- 自定义范围内的所有概览指标（汇总、分布、趋势、速度、缓存命中率）均按用户指定的 `[startAt, endAt)` 窗口计算，统计粒度可由用户选择。

## 范围

- 后端：扩展概览与全局概览接口的 `range` 枚举，新增 `custom` 值及可选 `startAt`/`endAt` query 参数。
- 前端：两个概览页面接入自定义时间范围 UI 与数据流。
- 重新生成 `openapi.yaml` 与 `dashboard/src/openapi-types.d.ts`。
