# JSON 查看器折叠对象的摘要

你看我们的 json viewer，一般都是用来看 agent trace 的，里面有些结构，比如 messages 里面的，一般都是一个数组，数组里面是 role，content 啥的。但是折叠起来的时候，只会显示一个 `{...}` 这个太单调了，能不能智能识别一下，把重点信息提取出来（截断一下），比如显示成 `{...} user Hello...` 这样的？tools 同理。其它的比如有 type 的，有 text 的，都可以提取出来嘛

## 补充

- 只给折叠的对象加摘要；折叠的数组仍然只显示 `[N 项]`。
- 实现完成后不做浏览器验证，由用户自己检查。
- 软换行模式下摘要所在的行也不换行，超出行宽的部分用省略号截断，省略号和被截断的文字同色。
- 摘要正文截断长度为 128 字符。
- 工具调用要显示工具名和参数：比如消息 `{role:"assistant", content:[{type:"tool_use", name:"Bash", input:{command:…}}]}` 应显示出 `Bash` 及其参数。
- 摘要里的 role 用 ink 色。
