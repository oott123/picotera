# 提案：模型历史费用重算

## 原始需求

在模型界面增加一个“重算历史”的按钮，点击之后打开侧栏，用户可以选择重算时间区间（24h/7d/30d/全部），选择提交之后，将重新计算选择区域内所有该模型请求的实际费用

## 规划阶段确认的补充约定

- **执行方式**：同步阻塞。提交后 HTTP 请求一直等到全部重算完成再返回汇总结果，侧栏期间只显示进行中状态；不引入后台任务、进度轮询或内存任务表。
- **不做预览**：不提供 dry-run 计数接口，选完区间直接执行，结果里返回本次重算的请求条数。
- **`range` 不设 enum**：请求体里是任意 Go duration 字符串，用 `time.ParseDuration` 严格解析（如 `24h`、`168h`、`720h`）；空字符串或省略该字段表示「全部（无下界）」。前端下拉框仍是 24h/7d/30d/全部 四档，发送时把天数换算成小时（7d → `168h`、30d → `720h`，全部 → 空串）。
- **区间控件是下拉框**（`Select` + `Field` 标签「时间区间」），不是分段控件（`SegmentedControl`）。
