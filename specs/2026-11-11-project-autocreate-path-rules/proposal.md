# 自动创建项目的路径规则

自动检测项目的时候，如果检测到 `/home/alice` 这样的路径，以 `/home` 开头且后面只有一个组件；或是 `/root` 或 `/tmp`；不自动创建项目
若是出现了 `/worktrees/`，则要创建自动项目时，自动去掉 `/worktrees/` 和其后所有组件

## 补充澄清

- 截断 `/worktrees/` 后，若最后一个组件是 `.claude` 或 `.codex`（白名单，仅这两个），再向上去掉一级；其他点开头的目录不做处理。例如 `<repo>/.claude/worktrees/<name>` → `<repo>`。
- 一次请求提取到多个路径时，被排除的路径只是不参与选种；其余合格路径中仍选最长的创建项目，只有没有合格路径时才不创建。
- Windows 路径同样处理：`\worktrees\` 同样截断（`.claude` / `.codex` 同样上移一级）；排除规则额外包含 `<盘符>:\Users\<x>`（`Users` 下只有一个组件），`/root`、`/tmp` 没有 Windows 对应项。
