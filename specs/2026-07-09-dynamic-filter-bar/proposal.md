# 动态筛选栏

## 需求

概览页面、请求页面这两个页面的顶部筛选框，改成一个筛选图标（filter-plus）按钮，点击之后，可以选择添加筛选的项目，添加之后，UI 里才会出现对应的下拉框。

在筛选标题后面，增加一个 X 按钮，点击就可以清除这个筛选项（移除该筛选项并恢复默认值）。

## 范围

- **概览页面（OverviewView）**：顶部所有筛选条件（时间范围、统计粒度、货币、密钥、请求模型、上游模型、渠道、项目）全部改为动态添加。
- **请求页面（RequestsView）**：页面上方输入区（类型、时间范围、ID、标注）改为动态添加。
- **全局概览页面（AdminOverviewView）**：同步改动（时间范围、统计粒度、货币、用户、请求模型、上游模型、渠道）。

图标使用 Tabler Icons 的 `FilterPlus`（`filter-plus`）。

## 非目标

- 不改动请求页面表格列头里的 ColumnFilter。
- 不改动现有筛选逻辑和数据流，仅改动 UI 的显隐与交互方式。
- 不引入 localStorage 持久化已添加的筛选项状态。
