# 请求页"状态"列改为显示"完成原因" + 增加筛选

将请求列表页的"状态"列改为直接显示"完成原因"（finish reason），并为完成原因增加筛选功能。

## 要求

- 请求列表页（`RequestsView`）的"状态"列改名为"完成原因"，直接显示完成原因文案（而非当前的"成功"/错误徽章逻辑）。
- 在该列表头增加 `ColumnFilter`，可按完成原因值筛选。
- 完成原因筛选项仅包含 7 个完成原因值（1=内部错误、2=已取消、3=正常结束、4=请求头超时、5=读取超时、6=流式错误、7=控制台打断），不包含"处理中"（在途请求不作为筛选项，但仍显示在列表中）。
- 请求详情面板（`RequestDetailsContent`）中已有的"停止原因"字段文案改为"完成原因"。
